## Зроблено з них
| Файл | Розмір | Як |
|---|---|---|
| `lewydo-x-header-1500x500.png` | 1500×500 (3:1) | X → шапка. Банер 1920×384 збільшено до висоти 500 (×1.302) і вирізано 1500 по ширині, знак на 40 px правіше центру (лівий низ у X закриває аватар). |

Рецепт (Python + Pillow), щоб повторити для іншого розміру:
```python
from PIL import Image
b = Image.open('owner/lewydo-banner-1920x384.png').convert('RGB')
x0, _, x1, _ = b.point(lambda v: 255 if v > 90 else 0).convert('L').getbbox()   # межі знака: 618…1283
k = 500 / b.height
s = b.resize((round(b.width * k), 500), Image.LANCZOS)
L = round((x0 + x1) / 2 * k) + 40 - 750
s.crop((L, 0, L + 1500, 500)).save('lewydo-x-header-1500x500.png', optimize=True)
```
Потрібна інша пропорція → бери оригінал, де знак уже має потрібний запас фону (широкі — з банера, високі — з 16:9),
і лише масштабуй та обрізай фон. **Знак не перемальовувати й не складати заново з інших шрифтів.**

## Стиль (заміряно з оригіналів)
- **Фон — майже чорний зелений `#000E03`** (банер; 16:9 — `#000D02`, аватар — `#000D04`). Не нічний синій сайту (`#0E1024`):
  у мережах студія — зелена.
- **Сітка клітинок** тонкими зеленими лініями, ледь помітна, тане до країв: на банері крок ≈ 23 px, на аватарі ≈ 105 px (5×5).
- **Серце бренду** (`brand_back` + `brand_front` з кіта) — заливка ≈ `#16A95C`, сильне м'ятне сяйво довкола.
- **Назва «LEWYDO™»** — великими, **жирний шрифт із засічками** (антиква), білий `#FFFFFF` з легким зеленим сяйвом; «™» — м'ятний ≈ `#4FEC8A`.
  ⚠ Це інший напис, ніж `lewydo.png` у кіті (округлий без засічок, як у грі). Для мереж — як в оригіналах; для ігор і сайту — кіт.
- **Лінія** під назвою, на всю її ширину — зелена ≈ `#41E782` (бренд `#3DDC84`).
- **Слоган «LOVE WHAT YOU DO»** — тим самим шрифтом із засічками, капсом, з великою розрядкою, зелений ≈ `#3CD478`.
- **Іскри** — дрібні зелені точки (≈ `#38D960`, деякі тьмяні `#0D6D26`) довкола знака, більше праворуч і над написом.
- Композиція: серце ліворуч, праворуч — назва / лінія / слоган, вирівняні по лівому краю; усе по центру кадру.
