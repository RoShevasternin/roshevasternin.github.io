# Сповіщення в грі: локальні з гри + глобальні FCM, мовою гравця, Android і iOS однаково, в усіх іграх студії

Власник 11.11.2026: «пуш сповіщення локальні з гри і глобальні з fcm … це дуже важливо для ретеншину … локальні обовʼязково
локалізовані по вибору мови юзера … головне що б це не додало багато мегабайт юзеру»; того ж дня: «круто що все таки можна і глобальні пуші
що б були мовою юзера». **Стандарт для всіх ігор студії** (Orbit Dash, CubePix, наступні). Еталон — Orbit Dash, патчі 132 (Android), 236
(мови), 242 (iOS локальні), 276 (iOS FCM), 338 (FCM мовою гри) і розклад FCM 11.11.2026 (`Orbit Dash/docs/notifications.md` у приватному
репо гри). Вставити в `CLAUDE.md` гри або дати сесії першим повідомленням.

## 1. Два види — і навіщо кожен

| вид | хто шле | коли | текст |
|---|---|---|---|
| **локальні** нагадування | сама гра (Android WorkManager, iOS UNUserNotificationCenter) | план на 90 днів, ставиться, коли гравець **іде** з гри; повернувся — знято весь | мовою гри, з **мовних пакетів гри** |
| **глобальні** FCM | сервер за розкладом (GitHub Actions → FCM HTTP v1) | тим, кого не було 5 / 9 / 14 тижнів, у **суботу ввечері** за їхнім часом; анонси оновлень | мовою гри, тексти **лише на сервері** |

Локальні — головні: точні (знають серію, рекорд, «майже пройдений» рівень) і без мережі. FCM — страховка там, де оболонка телефона вбила
локальну чергу (MIUI), і після 90-го дня. Дні FCM лягають між днями локальних (30 / 45 / 60 / 90) — двох за день не буває.

## 2. Локальні — правила

- **Дозвіл на старті не просимо.** Спершу свій лист гри з прикладом сповіщення й гарною кнопкою «Увімкнути» і тихим «Пізніше» — після
  моменту радості (нагорода дня, перша скриня), ≤ 3 разів за життя, ≥ 3 дні між ними; системне вікно — лише після «Увімкнути» (Android 13+
  дає 2 вікна, iOS — одне: спалити його без контексту не можна). Перемикача в налаштуваннях гри немає — вимикають у системі.
- **Не набридати:** ≤ 1 на день, година — звична година гравця (медіана останніх сесій, у межах 10–21; тиша вночі), ≤ 13 за 90 днів, далі
  тиша. Без шантажу втратою й обіцянок, яких гра не дає. Кожне веде на свій екран (`od_open` / свій ключ: missions, levels, shop, menu).
- **Мова — мова гри в мить планування** (не телефона). Змінив мову в грі — у черзі нічого не лишається (план знято), наступний вихід складе
  новою; канали Android теж перейменовуються мовою гри.
- **Повернувся — показане нагадування з шторки геть** (воно вже неправда); пуші FCM лишаються.
- Android: WorkManager, `OneTimeWorkRequest` із затримкою, без `SCHEDULE_EXACT_ALARM`; канал `reminders`, монохромна іконка статус-бару.
  iOS: `UNTimeIntervalNotificationTrigger`, ≤ 64 у черзі (план і так ≤ 13), делегат центру ставиться в `didFinishLaunching` (тап на холодному
  старті не губиться).
- Нове в сповіщеннях — **спершу прототип** (симуляція в DEBUG: кожен вид «прийти зараз», рядок плану, скинути), потім гра.

## 3. Глобальні FCM — правила

- **Теми, без бази користувачів.** Гра щостарту підписується на `all` (+ `debug` у debug-збірці) і на три теми розкладу:
  `seen_<ISO-рік>w<тиждень>` (тиждень останнього запуску), `tz_<p|m><години>` (зсув UTC), `lang_<id мови гри>` (`lang_uk`, `lang_zh-CN` —
  **мова гри, не телефона**); debug — з префіксом `dbg_`. «Не було 5 тижнів, Київ, українська» = умова
  `'seen_2026w36' in topics && 'tz_p2' in topics && 'lang_uk' in topics`. Змінив мову в грі — перепідписка одразу; до першої мови процесу
  (холодний старт) — та, на яку вже підписаний (інакше кожен старт смикав би підписку).
- **Розклад — вікно, а не година.** GitHub стартує cron не щогодини, а раз на 4–7 год (заміряно Orbit Dash, жовтень–листопад 2026:
  «рівно 18:00» влучало в 4–6 поясів із 27). Тому кожен запуск шле **всім** поясам, де зараз **субота 17:00–22:59** (запас — **неділя
  11:00–20:59**), яким цього вікенду ще не слали. «Кому вже» — стан (кеш Actions, ключ з `run_id` і `run_attempt`), пишеться **по ходу**;
  кеш загубився — пояси, які могли покрити попередні запуски вікенду (час з API GitHub), вважаються надісланими: краще пропустити, ніж
  двічі. Збій запуску → повідомлення власнику в Telegram.
- **Мови.** Сервер шле кожній мові гри її переклад із `campaigns.json` гри, немає перекладу — англійський. FCM обмежує одночасні
  розгортання умов (Orbit Dash: `429 Resource exhausted` уже на ~400 повідомленнях за хвилину), тож поштучно по мовах **не** шлемо: мова з
  перекладом — своє повідомлення, решта — ОДНЕ англійське «усім, крім мов із перекладом» (`… && !('lang_uk' in topics)`; ≤ 5 тем в умові,
  більше перекладів — англійське групами `(lang_a || lang_b || lang_c)`); 4 потоки, повтори 10 / 20 / 40 с на 429 / 5xx. Тексти **лише на сервері**: у застосунку 0 байт, новий переклад чи кампанія — без оновлення гри.
  Заголовок ≤ 40, текст ≤ 70 — у кожній мові. Переклад — коли англійські тексти готові, дешевою моделлю.
- **Формат повідомлення** (HTTP v1): `notification` + `android` (`channel_id` news, іконка, колір, `ttl` 6 год) + **`apns`**
  (`aps.sound: default`, `thread-id: news`, `apns-expiration` +6 год, `apns-priority` 10) + `data` (екран тапу, мітка кампанії). Без `apns`
  пуш на iPhone німий; без строку — запізнілий прийде за дні, вночі. Лише видимі пуші (data-only на iOS без розширення не покажеться).
- **Доступ без ключів:** Workload Identity Federation (пул `github`, провайдер лише на свій приватний репо й гілку `main`) → службовий
  акаунт з **однією** роллю Firebase Cloud Messaging Admin. Секретів у GitHub немає.
- **Хвилини:** cron лише на вікенд (UTC сб 03 … пн 08), пропущені слоти не коштують нічого — ≈ 10–13 запусків × 1 хв на вікенд
  (`github-actions.md`). Remote Config для сповіщень **не потрібен**: локальні тексти — у мовних пакетах, глобальні — на сервері.

## 4. iOS: де «галочки» (App Store Connect їх для пушів НЕ має)

| де | що зробити |
|---|---|
| developer.apple.com → Certificates, IDs & Profiles → **Identifiers** → App ID гри | увімкнути **Push Notifications** |
| там же → **Profiles** | перевипустити Development і App Store профілі ПІСЛЯ ввімкнення Push (у профілі з'являється `aps-environment`); завантажити, покласти в `release/ios/` |
| там же → **Keys** | ключ **APNs** `.p8` — один на команду (Team 3V79G27KZK — вже є: `AuthKey_F3LMM6A6PX.p8` у `release/ios/` Orbit Dash, підходить усім іграм команди); Apple видає файл лише раз |
| Firebase → Project settings → **Cloud Messaging** → Apple app configuration | **APNs Authentication Key**: `.p8`, Key ID, Team ID — для свого Firebase-проєкту гри |
| збірка | право `aps-environment`: App Store IPA — `production`, збірка з Мака — `development`; той самий тип у `setAPNSToken`; `FirebaseAppDelegateProxyEnabled = false` у Info.plist → токен APNs у FCM і облік відкриття — вручну |
| App Store Connect → **App Privacy** | Device ID (токен FCM), «не для трекінгу» |

**Пастка iOS (Orbit Dash, 338):** FCM віддає збережений токен раніше, ніж iOS — токен APNs; підписки на теми до `setAPNSToken` падають («No APNS token specified before fetching FCM Token»), і без повтору тиждень `seen_` застрягає — розклад шле «повертайся» тому, хто грав. Теми — лише після токена APNs (`onApnsToken` → підписки), збій — повтор. Мова гри на холодному старті ставиться окремим шляхом — перепідписку кличе й перша мова процесу.

`UIBackgroundModes remote-notification` **не потрібен** — лише для тихих data-only. Дозвіл — `requestAuthorization` з Alert + Sound (без
Badge і Provisional). Ці кроки сесія гри робить **сама через Chrome** (власник дає сесію з входом) — окрім паролів і оплат.

## 5. Android

`POST_NOTIFICATIONS` у маніфесті (targetSdk 33+), `firebase-messaging` (BoM), мета-дані FCM: іконка `ic_notification`, канал за
замовчуванням `news`, колір; свій `FirebaseMessagingService` — показ пуша, коли гра на екрані (тим самим виглядом). WorkManager для
локальних. Канали: `reminders` (локальні), `news` (FCM), назви — мовою гри.

## 6. Розмір

Локальні тексти — ключі i18n гри: ≈ 3–5 КБ на мову, а з мовними пакетами (AAB splits / ODR) гравець отримує лише свою. Глобальні — 0 байт.
SDK: `firebase-messaging` Android — сотні КБ; iOS `FirebaseMessaging.xcframework` — ≈ 1–2 МБ у IPA (виміряти до / після й записати в
патч гри).

## 7. Аналітика

`push_prompt {action}`, `push_permission {outcome}`, `notif_show {kind, day}`, `notif_open {source, day}`, властивість `notif_perm`
(granted / denied / blocked / never / off). **Не** `notification_*` — зарезервовані Firebase, подія мовчки зникне.

## 8. Перевірка перед злиттям

- чисті тести: план (дні, години, ліміти, мови), лист дозволу, тап → екран, теми (ISO-тиждень проти `java.time`, пояси з дробовою годиною,
  кожна мова гри дає дозволену тему = та сама, що в сервері), сервер — `selftest` (вікна, стан, повтори, об'єднання мов, межі cron);
- справжні пристрої (Android з MIUI і iPhone): DEV ✉ кожного виду, прискорений план, тап при живій грі й з холодного старту, зміна мови →
  перепідписка; FCM `run --test` на debug-теми: показ у фоні, звук на iPhone, тап → екран;
- `run --dry` (FCM `validate_only`) на справжньому проєкті — жодної помилки.

## Як зроблено в іграх

### Orbit Dash (еталон)
`services/notify` у `:core` (`NotifPlanner`, `PushAsk`, `NotifLaunch`, `NotifTopics`), Android — `NotifManager` / `NotifScheduler` /
`NotifWorker` / `Notifier` / `PushService`, iOS — `IOSNotify` / `IOSPush`; сервер — `docs/lab/analytics/fcm.py` + `docs/push/campaigns.json` +
`.github/workflows/push.yml`; редактор повідомлень — `docs/push/editor`.

### CubePix
Сповіщень ще немає (11.11.2026). План: після виходу першої iOS-версії — оновлення з пушами за цим правилом; сесія CubePix сама через Chrome
вмикає Push в App ID `com.lewydo.cubepix`, перевипускає профілі (App Store профіль зараз без `aps-environment`), кладе той самий ключ APNs у
Firebase `cubepix-1`, налаштовує Workload Identity для свого розкладу. Аудиторія спокійна — тим суворіше «не набридати».

## Готовий промпт для сесії гри

```markdown
## Сповіщення (рішення власника 11.11.2026, правило студії docs/process/notifications.md)

Локальні нагадування з гри + глобальні FCM за розкладом, Android і iOS однаково. Дозвіл — не на старті, а своїм листом після моменту
радості (≤ 3 рази, ≥ 3 дні); ≤ 1 на день у звичну годину гравця, ≤ 13 за 90 днів; план ставиться на вихід з гри, знімається на повернення;
показане нагадування при поверненні — з шторки геть. Тексти — МОВОЮ ГРИ: локальні — ключі i18n гри, глобальні — `campaigns.json` на
сервері (кожна мова — свій переклад або англійський; 0 байт у застосунку). Теми FCM: `all`, `seen_<ISO-тиждень>`, `tz_<зсув>`,
`lang_<мова гри>` (debug — `dbg_`); розклад — GitHub Actions лише у вікенд, кожен запуск шле поясам у вікні «субота 17–23, запас неділя
11–21», яким ще не слали (стан у кеші Actions по ходу), повідомлення з `apns` (звук, thread-id) і ttl 6 год, збій → Telegram. iOS: Push
в App ID, профілі заново, ключ APNs у Firebase, `aps-environment`, ручний `setAPNSToken` — сесія робить сама через Chrome. Спершу прототип
(симуляція в DEBUG), потім гра; еталон — Orbit Dash (патчі 132, 236, 242, 276, 338, `docs/notifications.md`).
```
