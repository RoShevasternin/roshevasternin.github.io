# Lewydo™ — сайт студії (https://roshevasternin.github.io/)

Спілкуйся з власником українською, дружньо й просто (він звертається «бро»). Це публічний репозиторій, GitHub Pages
публікує його корінь (гілка `main`). Сайти ігор — окремі репозиторії за адресами цього ж домену:
- `/Game-CubePix/` — RoShevasternin/Game-CubePix (збирається з приватного Game-CubePix-PRIVATE);
- `/Game-Orbit-Dash/` — RoShevasternin/Game-Orbit-Dash.

## Бренд — лише стандарт (рішення власника: «щоб це був стандарт всюди»)
**Джерело бренду для всіх проєктів Lewydo — сторінка https://roshevasternin.github.io/brand/ і тека `brand/` цього репозиторію.**
Власник дає новим проєктам лінк на неї замість Figma: звідти беруть лого, назву, слоган, пігулку для меню, BrandScreen, About us і серцебиття.
Сторінка 15 мовами, як увесь сайт (за замовчуванням — мова відвідувача, інакше англійська); тексти — `src/brand-strings.json`. Інформація публічна.

- **`brand/kit/png/`** — оригінали з ігор (Figma, **@3x**): `brand_back` 624 (сяйво), `brand_front` 420 (серце), `lewydo` 624×222,
  `slogan` 624×57, `brand_line` 438×3. Плюс `lockup.png` (увесь Lockup) і `pill.png` (пігулка меню, 118×36) — теж **експорти власника з Figma**.
- **`brand/kit/webp/`** — ті самі картинки для вебу (сайт показує знак саме ними). **`brand/kit/atlas/`** — атлас LibGDX (з Orbit Dash).
- **`brand/kit/code/libgdx/`** — `BrandScreen.kt`, `ABrandGroup.kt`, `ABrandLogo.kt` (код власника; додано лише один удар серця
  `beat(delay = 1.1f)` після появи), `LewydoHeartbeat.kt`. **`brand/kit/code/web/lewydo-brand.css`** — знак, пігулка, серцебиття й
  заставка для вебу; **цей самий CSS вбудовано в сторінки сайту** (`{{brandCss}}`), тож сайт і ігри показують знак однаково.
- **`brand/README.md`** (руками), **`brand/brand.json`**, **`brand/lewydo-brand-kit.zip`**, **`brand/index.html`** — генерує `npm run build`
  (шаблон `src/brand.html`, частини — `tools/brand.mjs`). Zip детермінований (без стиснення, фіксована дата).

**Стандарт (dp; картинки — @3x):**
- **Lockup 208×322:** коробка лого 208×208 — `brand_back` заповнює її, `brand_front` 140×140 по центру; назва 208×74; слоган 208×19
  (ніколи не перекладається); лінія 146×1 на 20 нижче. Масштаб у вебі — `--lw-s`.
- **Signature:** лого 24 + 1 + назва 46.1×16.4. **Пігулка меню:** висота 28 (рішення власника, у Figma була 36), рамка #3DDC84 24 %,
  фон 4 %, › #9DF5C2; внизу меню по центру, 34 від низу; тап → About us.
- **BrandScreen:** серце 0.3→1.1 с, один удар на 1.1; назва 0.9→1.5 і слоган 1.3→1.9 (scale 1.06→1); лінія 1.7→2.4 (exp5Out);
  0.6 с паузи → LoaderScreen. Ігри можуть міняти лише **фон і підсвітку** під свою тематику, знак — ніколи.
- **About us** (Figma «01 About Us»): Lockup на 108, текст на 456 шириною 312, кнопки 296×52 на 584 і 682, адреса на 648, © на 764.
- **Кольори:** #0E1024 фон, #6DF593 сяйво, #3DDC84 кнопка (текст #04120A), #9DF5C2 м'ятний, #FFFFFF. Шрифт Nunito.
- **Серце б'ється один раз**, коли знак з'являється, ніколи в циклі. «Менше руху» в системі — без анімацій.

**Картинки кіта (`brand/kit/png/`) — лише те, що власник експортував з Figma** (@3x; останній зіп «FIGMA BRAND»: brand_back, brand_front,
lewydo, slogan, brand_line, Lewydo/Lockup → lockup.png, Lewydo/Signature → pill.png). Нові експорти → туди ж, потім перезібрати атлас
(`brand/kit/atlas/brand.png`: ті самі xy з `brand.atlas`, лише вставити нові картинки) і WebP-копії в **повному** розмірі
(brand_back q90, brand_front q94, решта lossless), далі `npm run build`. Фавікон, іконки, `assets/og.png`, `logo.png`, `banner.png`,
`brand.png` малює `npm run kit` з картинок кіта й CSS. Руками їх не малювати.

## Що на сторінці
1. **Герой:** пікселі в кольорах усіх ігор злітаються в серце Lewydo, воно оживає й б'ється один раз. Тап по серцю — усе знову.
2. **Світи ігор:** на кожній грі сторінка змінює вигляд (фон, «небо», акцентний колір).
   - **CubePix** (новинка): картини музею розкриваються шар за шаром у золотій рамі. «Спробуй сам» — маленька головоломка
     з полуницею, як у грі.
   - **Orbit Dash** (уже в Google Play): міні-гра «дві орбіти, один тап». Поки не натиснеш, грає сама.
3. **Більше від Lewydo:** картки інших ігор, що нахиляються за курсором.
4. **Студія:** текст «Про нас» (як у іграх), цифри, картка «код ↔ дизайн» з повзунком і картки Влада та Лілі.
5. **Історія:** 2017 Java → 2021 геймдев → 14.10.2022 Влад ❤ Ліля → 2025 народження Lewydo (підпис статей Влада на Medium: «Love what you do» + 💚)
   → 21.04.2026 IMC → 03.05.2026 ідея CubePix (Влад у ЗСУ, на виїзді) → 14.07.2026 побралися → 30.08.2026 Orbit Dash → 30.09.2026 прототип
   CubePix → жовтень 2026 CubePix у Google Play (пунктир — ще попереду). Лінія заповнюється, поки читаєш. Далі **контакти** й підвал із підписом-«пігулкою».
6. **`/brand/` — вкладка «Бренд»** (у меню й підвалі; посилання й під карткою «код ↔ дизайн»): як упізнати Lewydo, правила,
   кольори, три телефони (BrandScreen з перемикачем фонів ігор, About us 15 мовами, меню з пігулкою), серцебиття з графіком і кодом,
   завантаження, інструкція для розробників і готовий текст для Claude в іншому проєкті.

Мова: `?lang=xx` → вибір відвідувача (localStorage `lewydo:lang`; той самий вибір підхоплює сайт CubePix) → мова пристрою → англійська.

## Команди
```bash
npm install            # один раз (лише Playwright для тестів)
npm run build          # src/ → сторінки в корені
npm test               # збірка --strict (жодного пропущеного перекладу) + тести: мови, 320 px, серце, обидві гри, 404, app-ads.txt, сторінка бренду й усі її файли
npm run look           # сторінка картинками (телефон і ПК) → shots/ — ПОДИВИСЬ і покажи власнику (LANGS=uk,en; PAGE=brand — сторінка бренду)
npm run kit            # картинки сайту з кіта (іконки, OG, logo/banner/brand.png)
npm run serve          # http://localhost:5190/
npm run cubepix -- <клон RoShevasternin/Game-CubePix>/index.html   # оновити дані CubePix з його сайту
```

## Правила
- **Жодних сторонніх запитів:** шрифти, картинки, скрипти — лише з цього сайту (це перевіряє `npm test`). Посилання — можна.
- **Сторінка бренду — теж 15 мовами** (`src/brand-strings.json`; `npm test` не пропустить незаповнений переклад). Тексти About us на ній беруться з гри (`src/cubepix.json`). Не перекладаються: Lewydo, «Love What You Do», назви ігор і файлів, код у `…`.
- **Вирівнювання:** блок із `max-width` у центрованій секції — з `margin-left/right:auto`; групи кнопок на телефоні — однакової ширини. Перевір `npm run look` кількома мовами.
- **Кожен текст — 15 мовами.** Англійська — еталон, тон теплий і живий. Не перекладаються: назви ігор, «Lewydo», «Love What You Do»,
  «Google Play». Слова про CubePix беруться з самої гри (`cp:…`), а не пишуться заново.
- **Нова гра:**
  1. іконка 192 px і банер 800 px → `python3 tools/webp.py <файл> assets/games/<id>-icon.webp 192`;
  2. запис у `src/games.json`;
  3. два тексти `game.<id>.genre` і `game.<id>.d` усіма 15 мовами;
  4. `npm run build`, `npm test`, `npm run look`.
- **Гра вийшла в Google Play** (наприклад, CubePix): `src/games.json` → `released: true`. Потім перевір кнопку в її світі.
- **Перевір на телефоні (320–390 px) і ПК:** `npm run look` і подивись PNG. «Парситься» — ще не «виглядає добре».

## Git і публікація
Робоча гілка `claude/…` → PR у `main` → злиття (merge) → GitHub Pages оновлює сайт за хвилину-дві.
Власник працює у веб-сесіях і localhost не відкриє. Великі зміни спершу покажи йому картинками з `npm run look`.
З будь-якого акаунта Claude — так само: потрібен лише підключений GitHub з доступом до цього репозиторію.
На Mac власника — `git pull` перед роботою.

## Відкриті питання й наступні кроки (онови, коли власник вирішить)
- **Висота пігулки меню:** у стандарті й CSS — **28** (раніше вирішив власник), а `pill.png` з Figma, який він дав останнім, — **36** (118×36).
  Запитати, яка висота — стандарт, і вирівняти все під неї (CSS кіта, `brand.json`, сторінка, `LEWYDO_BRAND.md` у CubePix).
- **Orbit Dash** (`who_made/ABrand.kt`): серце б'ється в циклі (`Actions.forever`) — проти стандарту «один раз». Запропоновано виправити.
- **CubePix вийде в Google Play в жовтні 2026** — власник скаже точну дату. Тоді: в історії (`story.next.*` у `src/strings.json`, 15 мов) — точна
  дата «dd · mm · 2026», заголовок «CubePix у Google Play» і текст у минулому часі, клас `next` у `src/index.html` прибрати; `src/games.json` → `released: true`.
- Більша роздільність за @3x — лише новим експортом з Figma (серце растрове, збільшувати не можна).
