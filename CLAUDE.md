# Lewydo™ — сайт студії (https://roshevasternin.github.io/)

Спілкуйся з власником українською, дружньо й просто (він звертається «бро»). Це публічний репозиторій, GitHub Pages
публікує його корінь (гілка `main`). Сайти ігор — окремі репозиторії за адресами цього ж домену:
- `/Game-CubePix/` — RoShevasternin/Game-CubePix (збирається з приватного Game-CubePix-PRIVATE);
- `/Game-Orbit-Dash/` — RoShevasternin/Game-Orbit-Dash.

## Бренд — лише стандарт (рішення власника: «щоб це був стандарт всюди»)
Знак Lewydo тут **точно за бренд-стандартом**: Figma «00 Brand», компоненти «Lewydo / Lockup» і «Lewydo / Signature».
Повний опис — `cubepix/docs/brand/LEWYDO_BRAND.md` у Game-CubePix-PRIVATE. Не перемальовувати, не перефарбовувати,
не міняти шрифт і пропорції.

**Lockup 208×322:**

- сяйво #6DF593 — силует сердечка ×1.235, blur 12.2;

- слоган «Love What You Do» — Nunito 13.54, літери L, e, W, Y, Do — Black. Слоган **ніколи не перекладається**;
- лінія 146×2.

**Signature (підпис-«пігулка»):** сердечко 16 у сяйві + «Lewydo» Nunito Black 12. Капсула 28 px, рамка #3DDC84 24 %.

**Кольори:** #0E1024 фон, #6DF593 сяйво, #3DDC84 кнопка, #9DF5C2 м'ятний, #FFFFFF. Кнопки 52 px, радіус 16.

**Серце б'ється один раз**, коли з'являється, ніколи в циклі. «Менше руху» в системі — без анімацій.

**Картинки знака:**
- малюнок сердечка — `assets/lewydo-heart.webp` (з `tools/brand/export` гри);
- фавікон, іконки, `assets/og.png`, `logo.png`, `banner.png`, `brand.png` малює `npm run kit` з того самого CSS. Руками їх не малювати.

## Як влаштовано
| Файл | Що це |
|---|---|
| `src/index.html` | шаблон сторінки: CSS і скрипт усередині; `{{…}}` і `data-t` заповнює збірка |
| `src/strings.json` | усі тексти сайту 15 мовами (англійська — еталон) |
| `src/games.json` | ігри: адреси, Google Play, кольори, іконки, `released` |
| `src/cubepix.json` | CubePix: картини, назви, слова гри (зокрема текст «Про нас» — однаковий у всіх іграх), лого. **Генерує** `npm run cubepix` |
| `src/langs.json` | 15 мов з піксельними прапорцями (ті самі, що в іграх) |
| `src/heart.kt` | код, з якого «складається» серце в картці «Він кодить. Вона малює» |
| `src/404.html` | сторінка «кімнати немає» для **всього** домену (тому всі шляхи абсолютні) |
| `tools/build.mjs` | збірка → `index.html`, `404.html`, `robots.txt`, `sitemap.xml` у корені |
| `tools/webp.py`, `tools/fetch-fonts.py`, `tools/cubepix-snapshot.mjs` | картинки → WebP; шрифти (Nunito, літери ORBIT DASH з Unbounded); дані CubePix |
| `tests/` | `npm test` (`site.spec`), `npm run look`, `npm run kit`; `serve.mjs` — сервер як GitHub Pages |
| `app-ads.txt` | **для AdMob — не чіпати й не видаляти** (без нього реклама в іграх заробляє менше) |
| `assets/` | шрифти, серце, іконки й банери ігор, `og.png`, іконки сайту |

`index.html`, `404.html`, `robots.txt`, `sitemap.xml` у корені **згенеровані**: правити `src/`, потім `npm run build`.

## Що на сторінці
1. **Герой:** пікселі в кольорах усіх ігор злітаються в серце Lewydo, воно оживає й б'ється один раз. Тап по серцю — усе знову.
2. **Світи ігор:** на кожній грі сторінка змінює вигляд (фон, «небо», акцентний колір).
   - **CubePix** (новинка): картини музею розкриваються шар за шаром у золотій рамі. «Спробуй сам» — маленька головоломка
     з полуницею, як у грі.
   - **Orbit Dash** (уже в Google Play): міні-гра «дві орбіти, один тап». Поки не натиснеш, грає сама.
3. **Більше від Lewydo:** картки інших ігор, що нахиляються за курсором.
4. **Студія:** текст «Про нас» (як у іграх), цифри, картка «код ↔ дизайн» з повзунком і картки Влада та Лілі.
5. **Історія:** лінія заповнюється, поки читаєш. Далі **контакти** й підвал із підписом-«пігулкою».

Мова: `?lang=xx` → вибір відвідувача (localStorage `lewydo:lang`; той самий вибір підхоплює сайт CubePix) → мова пристрою → англійська.

## Команди
```bash
npm install            # один раз (лише Playwright для тестів)
npm run build          # src/ → сторінки в корені
npm test               # збірка --strict (жодного пропущеного перекладу) + тести: мови, 320 px, серце, обидві гри, 404, app-ads.txt
npm run look           # сторінка картинками (телефон і ПК) → shots/ — ПОДИВИСЬ і покажи власнику (LANGS=uk,en)
npm run kit            # картинки бренду з CSS стандарту
npm run serve          # http://localhost:5190/
npm run cubepix -- <клон RoShevasternin/Game-CubePix>/index.html   # оновити дані CubePix з його сайту
```

## Правила
- **Жодних сторонніх запитів:** шрифти, картинки, скрипти — лише з цього сайту (це перевіряє `npm test`). Посилання — можна.
- **Кожен текст — 15 мовами.** Англійська — еталон, тон теплий і живий. Не перекладаються: назви ігор, «Lewydo», «Love What You Do»,
  «Google Play». Слова про CubePix беруться з самої гри (`cp:…`), а не пишуться заново.
- **Нова гра:**
  1. іконка 192 px і банер 800 px → `python3 tools/webp.py <файл> assets/games/<id>-icon.webp 192`;
  2. запис у `src/games.json`;
  3. два тексти `game.<id>.genre` і `game.<id>.d` усіма 15 мовами;
  4. `npm run build`, `npm test`, `npm run look`.
- **Гра вийшла в Google Play** (наприклад, CubePix): `src/games.json` → `released: true`. Потім перевір кнопку в її світі.
- **Перевір на телефоні (320–390 px) і ПК:** `npm run look` і подивись PNG. «Парситься» — ще не «виглядає добре».

## Git і публікація
Робоча гілка `claude/…` → PR у `main` → злиття (merge) → GitHub Pages оновлює сайт за хвилину-дві.
Власник працює у веб-сесіях і localhost не відкриє. Великі зміни спершу покажи йому картинками з `npm run look`.
З будь-якого акаунта Claude — так само: потрібен лише підключений GitHub з доступом до цього репозиторію.
На Mac власника — `git pull` перед роботою.
